# Tussle Arena — Multi-Level Brawler

Five progressively harder levels. Each level adds one opponent (Level 1: one rival; Level 5: five rivals). Enemy HP and damage scale by level. Player starts with 160 HP and incoming attacks have lower damage to make fights less punishing.

## Controls
- A / D: move left / right
- W: jump
- S: crouch
- J: quick hand punch
- K: heavy hand punch
- U: quick leg kick
- I: heavy leg kick
- L: block
- Enter: start
- Restart: return to Level 1

Open `index.html` in a modern browser or use VS Code Live Server. No build step or external JavaScript libraries required.
